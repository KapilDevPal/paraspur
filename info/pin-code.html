How PIN Code 271504 is Structured

The Postal Index Number (PIN) system in India consists of 6 digits. Here is the breakdown for 271504:

  • First Digit (2): Represents the Northern Postal Region (covering Uttar Pradesh and Uttarakhand).
  • Second Digit (7): Represents the sub-region (Uttar Pradesh Circle).
  • Third Digit (1): Represents the revenue sorting district (Gonda District).
  • Last 3 Digits (504): Indicates the specific delivery post office (Paraspur Sub Post Office).
